# لوحة تحليل نتائج الأعمال

لوحة تحكم تفاعلية لتحليل بيانات العملاء والعقود والإيرادات.

## المميزات
- نظرة عامة على الأداء الرئيسي
- تحليل اتجاهات العملاء
- تتبع نمو الإيرادات
- مقارنة بين العقود الجديدة والمجددة
- توزيع العملاء حسب الأقسام
- جداول قابلة للتنزيل

## كيفية الاستخدام
1. ارفع ملف Excel من خلال الزر في الشريط الجانبي
2. استخدم الفلاتر لتخصيص العرض
3. استكشف الأقسام المختلفة من لوحة التحكم
4. نزل الجداول التي تهمها كملفات Excel

## هيكل ملف البيانات
يجب أن يحتوي ملف Excel على الأعمدة التالية:
- Company Name
- Department
- Renewal Number
- Renewal Date
- Contract Duration (Months)
- Cost
